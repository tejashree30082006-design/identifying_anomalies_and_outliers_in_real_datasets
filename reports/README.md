# Generated Reports Directory

This directory stores exported analytical reports and structured summaries generated by the application.

### Available Export Formats
1. **Markdown / Text Reports (`.md`)**: Comprehensive analytical dossiers containing dataset dimensions, data quality audits, descriptive statistics, outlier detection tallies, hypothesis test decisions, and academic disclaimers.
2. **JSON Summaries (`.json`)**: Machine-readable statistical configurations and analytical metrics with sanitized, JSON-safe values (handling NaN and Infinity).
3. **CSV Tables (`.csv`)**:
   - Flagged observations table with original row numbers and deviation metrics.
   - Descriptive statistics summary table.
   - Full detection results table.

All generated reports clearly state the methodological disclaimer:
> *Statistical outlier detection identifies distributional nonconformities. It cannot confirm intentional data fabrication.*
